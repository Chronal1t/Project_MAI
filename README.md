# Task Manager (C++ backend)

## Сборка
    cd backend
    build.bat

## Запуск
    cd backend
    run.bat
    → http://localhost:8080

## Требования
- Visual Studio 2022 (MSVC, C++17)
- SQLite amalgamation в backend/third_party/

## Структура
- backend/src — исходники
- backend/third_party — sqlite3
- frontend — web UI
- docs — api.md, architecture.md
